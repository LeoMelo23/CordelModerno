## 📋 Sobre o projeto

O **Cordel Moderno** é um projeto de estudo proposto pelo professor Gustavo Guanabara através do seu curso de HTML, CSS no canal do <a href="https://www.youtube.com/results?search_query=curso+em+video" a/> Curso Em Video

## ✨ Funcionalidades

- 📱 **Layout responsivo** — adapta-se a celulares, tablets e desktops
- 🎨 **Design elegante** — paleta de cores e tipografia pensadas para moda
